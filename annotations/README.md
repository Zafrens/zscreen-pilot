# Control target annotations

**MSC1094308 (`CPD_780406670572`) inhibits VCP/p97 and VPS4B.** Primary
biochemical characterization identifies reversible allosteric inhibition of
these AAA ATPases. [Pöhler et al., 2018](https://pubmed.ncbi.nlm.nih.gov/29271116/).

[control_target_annotations.csv](control_target_annotations.csv) records
the public compound ID, control name, initiating targets, mechanism class
and primary-study citation. Response similarity to this control does not
establish the same molecular targets for a library compound.

The [correspondence annex](../annex_phenomimicry/README.md) provides
method-specific reference comparisons and known-control calibration.
Its `target_gene` identifies the genetic signature being compared, which
is distinct from the control's pharmacological target annotation.
