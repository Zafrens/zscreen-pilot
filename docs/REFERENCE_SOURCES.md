# Public reference studies and source terms

Z-Screen chemical measurements, public recipes and model components are accompanied by selected comparisons with external genetic perturbations. Cite the corresponding original studies when using these result fields. The references below are independent resources with their own data access and reuse terms.

## Endothelial genetic reference

The HSPA5-associated AEC7 family and partner comparisons use a **teloHAEC genetic reference**, from Schnitzler et al., *Nature* (2024), [doi:10.1038/s41586-024-07022-x](https://doi.org/10.1038/s41586-024-07022-x), [GEO GSE210681](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE210681), within [GSE210523](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE210523). Zafrens chemical measurements are **AEC7**; the two cell-line identities remain distinct. [Score definition and data access](ANALYSIS_ACCESS.md).

No explicit submitter data license is identified here for that underlying GEO dataset. Obtain the source under the provider's terms; this package grants no additional rights over external data or their source-specific result portions. Zafrens core measurements and generic code have their own component licenses.

## HEK293T genetic reference

The METTL3 selection example uses the HEK293T genetic reference from Xaira Therapeutics / Huang et al., [X-Atlas/Orion](https://doi.org/10.1101/2025.06.11.659105). The [source dataset card](https://huggingface.co/datasets/Xaira-Therapeutics/X-Atlas-Orion/blob/main/README.md) specifies CC BY-NC-SA 4.0. The corresponding HEK score/reward-derived portions of the selection tables and mixed figures retain that [source-specific notice](../LICENSES/CC-BY-NC-SA-4.0.txt). Independent chemical data and generic software remain separate components.

## Multi-reference chemical–genetic comparisons

The [phenomimicry guide](../annex_phenomimicry/README.md) identifies the public studies, dataset keys and definitions used in its correspondence tables. Its consensus scores differ from the signed top-gene scores used in the family/selection examples. These are processed comparison results; the underlying reference cells and genetic matrices are obtained from their original providers.
