# Examples of what the pilot data can answer

These three examples connect repeated chemical components, cellular responses and the choice of further measurements. The tables and figures show family coherence, partner-associated response differences and retrospective experiment selection.

| Example | What it shows | Included evidence |
|---|---|---|
| [A shared component and an HSPA5-associated response](01_hspa5_building_block/README.md) | A filtered 1,512-compound family has closely agreeing aggregate RNA profiles across different member compounds. | Family support, correlation and genetic-correspondence summary |
| [Comparing chemical partners](02_partner_responses/README.md) | Partner-defined groups have different aggregate reference correspondences; a causal mechanism switch remains unconfirmed. | Response figure, full/half scores, recipe coordinates and matched-endpoint summary |
| [Learning which recipes to measure next](03_adaptive_replay/README.md) | Updating a model improves recovery of a fixed high-score set in a retrospective replay. | Selection curves, per-start results, endpoints and task definitions |

Each example includes the values, units and interpretation needed to inspect its results. The public core supplies recipes, response surfaces and reference models for further analysis. [Data scope](../docs/ANALYSIS_ACCESS.md) · [Genetic-reference sources](../docs/REFERENCE_SOURCES.md).
